# Plans

This directory contains implementation-ready plans for features in this add-on.

## Conventions

- Use one Markdown file per feature with a lowercase kebab-case name.
- Keep plans focused on decisions, scope, implementation steps, validation, and open questions.
- Revise the plan when requirements change before beginning a substantial implementation slice.
- Move completed plans to `plans/completed/` only when the feature is fully delivered and validated.

## Template

```markdown
# Feature Name

One-sentence description of the intended outcome.

## Goals

## Decisions

## Scope

## Implementation Steps

## Validation

## Open Questions
```
